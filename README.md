# Cartes HBLM

Appli web (PWA) du jeu de cartes à collectionner des licenciés du Handball Lunel Marsillargues.

- Publiée automatiquement par Netlify à chaque modification de la branche `main` (pas de build : le dossier racine est publié tel quel).
- Les données (licenciés, collections, échanges, photos) sont dans Supabase et ne sont visibles qu'après connexion avec le code du club.
- Ce dépôt ne contient ni nom de licencié, ni photo, ni code du club.
